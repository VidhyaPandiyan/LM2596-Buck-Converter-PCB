# LM2596-Buck-Converter-PCB
12V to 5V Buck Converter PCB designed in KiCad

## Overview

A compact 12V to 5V DC-DC buck converter designed using KiCad and based on the LM2596S-5.0 switching regulator.

## Features

* 12V DC Input
* Regulated 5V Output
* LM2596S-5.0 Switching Regulator
* Reverse Polarity Protection
* Power Indicator LED
* Input and Output Filtering Capacitors
* Designed in KiCad

## Applications

* ESP32 Projects
* Arduino Projects
* IoT Devices
* Sensor Nodes
* Embedded Systems

## Tools Used

* KiCad
* PCB Editor
* KiCad 3D Viewer
